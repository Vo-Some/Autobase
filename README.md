# Autobase

Консольное Java-приложение для управления автотранспортным предприятием. Позволяет вести учёт заказов на перевозку грузов, управлять водителями и грузовиками.

## Возможности

- Создание **обычных (Regular)** и **срочных (Express)** заказов на перевозку
- Автоматическое **слияние заказов** одного типа груза в одно направление
- Учёт **водителей** (база данных с сохранением)
- Учёт **грузовиков** (модель, грузоподъёмность, водитель)
- Три типа груза: `BUILDING`, `FOOD`, `TECH`
- Сохранение и загрузка заказов в бинарный файл (`orders.dat`)
- Загрузка заказов из текстового файла (`.txt`)
- Интерактивное консольное меню

## Требования

- Java 17+
- Maven 3.6+

## Сборка и запуск

```bash
# Сборка проекта
mvn package

# Запуск
java -cp target/autobase-1.0-SNAPSHOT.jar com.autobase.main.Autobase
```

## Структура проекта

```

├── Autobase.java                        # Главный класс, меню приложения

│   └── DriverDatabase.java              # Singleton-база данных водителей

    ├── Cargo.java                       # Груз
    ├── OrderRepository.java             # Сохранение/загрузка заказов
    └── typeoforder/

```

## Файлы данных

| Файл          | Описание                                        |
|---------------|-------------------------------------------------|
| `orders.dat`  | Бинарный файл с заказами (автосохранение)       |
| `drivers.dat` | Бинарный файл с базой водителей (автосохранение)|
| `base.txt`    | Пример текстового файла для импорта заказов     |

### Формат текстового файла заказов (`base.txt`)

```
ТИП;Откуда;Куда;ТипГруза;Вес;Доплата;МодельГрузовика;Грузоподъёмность;ИмяВодителя;Опыт
```

Пример строк:
```
REGULAR;Germany;France;TECH;4000.0;0;Volvo;5000.0;Jake;7
EXPRESS;Germany;Poland;BUILDING;2000.0;500.0;Benz;5000.0;Harry;4
```

> Для `REGULAR`-заказов поле `Доплата` равно `0`.

## Меню приложения

```
 Autobase Menu
1. Add Regular Order      — добавить обычный заказ
2. Add Express Order      — добавить срочный заказ
3. Print All Orders       — вывести все заказы
4. Save orders            — сохранить в orders.dat
5. Load orders            — загрузить из orders.dat
6. Load orders.txt        — загрузить из текстового файла
7. Manage Drivers         — управление водителями
0. Exit                   — выход (с автосохранением)
```

### Управление водителями (меню 7)

```
 Driver Management
1. Add new driver    — добавить водителя
2. View all drivers  — список всех водителей
3. Remove driver     — удалить водителя
0. Back
```

## Логика заказов

- **RegularOrder** — стандартная стоимость: `вес × GLOBAL_RATE`
- **ExpressOrder** — стоимость: `вес × GLOBAL_RATE + доплата`
- Два заказа **сливаются** автоматически, если совпадают тип груза и направление (`to`)
